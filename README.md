# loyalty-mvp

# Figma Make prototype

front-end prototype of the loyalty card platform, made in Figma Make.
All data is made up and nothing is connected to the Flask backend.

## First time

1. Install Node.js from nodejs.org
2. Install pnpm: `npm install -g pnpm`
3. In this folder, run: `pnpm install`

## Every time

1. In this folder, run: `pnpm dev`
2. Open the Local link it prints, e.g. http://localhost:8443/
